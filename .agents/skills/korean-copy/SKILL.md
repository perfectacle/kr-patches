# 한국어 문구

이 스킬이 COPY-01 의 정본이다. 대상은 모든 `*.ko.md` 다. 에이전트 문서(`AGENTS.md`, `.agents/`)는 한다체로 짧게 쓴다. 패치 안의 대사·이름(`tables/`, `data/`)은 번역 데이터라 이 스킬의 대상이 아니다.

## 규칙

- **어조**: 사용자 문서는 합니다체. 분석 노트 안의 코드 블록 메모처럼 짧은 기록은 기존 문체를 따른다. 한 문서 안에서 섞지 않는다.
- **영어판을 옮기지 말고 한국어로 다시 쓴다**: 내용은 영어판과 같게([DOC-01](../game-patch/SKILL.md#doc-01--영어판과-한국어판)), 문장은 한국어 순서로.

  | 피할 것                         | 쓸 것                 |
  | ------------------------------- | --------------------- |
  | `X 에 대한 지원을 추가했습니다` | `X 를 지원합니다`     |
  | `~하는 것이 가능합니다`         | `~할 수 있습니다`     |
  | `성공적으로 ~되었습니다`        | `~했습니다`           |

- **이름은 하는 일 그대로 짓는다**: 도구·스크립트·절 제목을 비유로 짓지 않는다.
- **게임 안의 이름은 패치 대사를 따른다**: 등장인물·적·아이템 이름은 흔한 번역이 아니라 이 패치의 대사(`tables/`, `data/`)에 나온 표기를 쓴다. 문서를 읽는 사람이 패치한 게임에서 보는 이름과 같아야 한다.

## 용어집

같은 개념은 한 용어로 쓴다.

| 개념                                 | 쓸 말                                           |
| ------------------------------------ | ----------------------------------------------- |
| ROM / dump                           | 롬 / 덤프                                       |
| Super Famicom                        | 슈퍼패미컴(SNES)                                |
| Nintendo DS / game card              | 닌텐도 DS / 게임 카드                           |
| font(롬 안의 글자 데이터) / glyph    | 폰트 / 글리프                                   |
| typeface(시스템·배포 서체)           | 글꼴                                            |
| script(대사 전체) / line             | 대본 / 대사                                     |
| character code table                 | (문자) 코드표                                   |
| hook, IPS, xdelta, CRC32, SHA-1, VRAM, WRAM | 영어 그대로                              |
| 제품 이름                            | 원어 그대로(Mesen 2, asar, libretro, macOS, Galmuri) |
